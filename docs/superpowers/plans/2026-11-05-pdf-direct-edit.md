# Direct PDF editing and visual navigation

The native PDF document now opens the shared editor immediately. Reading mode remains available for files whose editing runtime is not ready. Fixed-page editing retains the source PDF geometry; a separate, explicitly confirmed “문서로 편집” action imports selectable text into the regular document editor for paragraph editing. This import is not a layout reconstruction and the confirmation explains the effect.

Page navigation lazily renders thumbnails near the viewport. Revision changes refresh thumbnails without replacing existing previews with blank cards. Object rows use T for text and rendered page-region previews for shapes/images. Text hit targets take priority over page-sized backgrounds. Double-clicking text opens an on-page input with Enter/blur to apply and Escape to cancel.

Validation uses optional local multipage fixtures, never checked into the repository. The document UI regression exercises thumbnails, object previews, overlapping hit targets, inline Korean editing, transforms, deletion/undo, copy saving, document import dispatch, and unchanged source hashes. The native lifecycle test requires immediate editing mode and checks deferred close during an edit. Existing worker and GUI checks remain applicable.

Continuation: eight resize handles transform the real PDF object while preserving the opposite anchor. Shift locks the visual aspect ratio; page rotation swaps scale axes and maps center movement into PDF coordinates. Escape cancels without a revision. Handles sit outside the object so small text stays clickable. Context menus expose text/image editing, rotation and deletion. Page number, previous/next and Page Up/Down navigate without thumbnail scrolling; page/width zoom modes track workspace size.

Input reliability: save/navigation actions await any pending inline edit. A failed edit restores the draft after its error popup. Both hosts track uncommitted input for close confirmation, with cancellation returning to the revision's existing dirty state. Current-page find supports case-insensitive normalized Korean text, match highlighting and next/previous selection. The object list can filter text, images, paths and groups.

2026-11-05 correction: reproduced surrounding artwork turning black after replacing a title in a CMYK textbook cover. PDFium regeneration lost inherited paint state. Before generating edited content, materialize the resolved fill/stroke RGBA for existing path/text siblings. A standalone CMYK regression fails before the fix and passes after it; source PDFs remain unchanged.

OCR-backed outline selection groups contained path components into a named visual title. Backgrounds outside the recognized region are excluded; a detail toggle retains access to original paths. Batch operations use a common group pivot. This is visual grouping, not recovery of the original font or editable text semantics. Full PDF selection, additive selection, marquee selection and pinch zoom are supported. Native document/slide/sheet selection continues to use its existing editor; missing sheet/slide magnification and portable workspace gestures are added.

Printing and fonts: PDF/slide/sheet documents now supply native PDF print operations, using the OS print panel and its configured destinations/options. PDF print actions commit inline drafts first and print the current revision. Portable editors export a private PDF snapshot and request the system print dialog in an isolated preview window; closing/canceling resolves without sending a job. Physical printing/fax transmission requires user confirmation and compatible OS destinations; no test sends a print job.

Font replacement first attempts reusable embedded font data with glyph coverage. Otherwise installed TTF/OpenType/TTC faces are ranked by normalized family/name, weight, width class, italic and serif traits, then checked for required glyphs. CFF OpenType faces retain their sfnt cmap when loaded, and Unicode aliases not requested by the input are removed to avoid a space becoming NBSP. Matching is heuristic when the original subset font lacks new glyphs or the original face is unavailable.
