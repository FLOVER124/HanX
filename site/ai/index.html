웹·앱 AI

hanx connect로 이 컴퓨터의 HanX에 연결 주소를 만듭니다.

1. HanX 설치

어느 방법이든 먼저 HanX CLI를 설치합니다. macOS 13 이상, Windows x64, Ubuntu 22.04 이상 x64를 지원합니다.

npm install -g @flover124/hanx

npm에는 Node.js 18 이상이 필요합니다. macOS·Linux에서는 brew install FLOVER124/tap/hanx도 쓸 수 있습니다. 자세한 내용은 사용 안내를 보세요.

2-A. 내 컴퓨터의 AI 도구에 연결

Claude Code

HanX 플러그인을 설치하면 연결과 사용 안내가 함께 들어옵니다.

/plugin marketplace add FLOVER124/HanX
/plugin install hanx@hanx

Codex

codex mcp add hanx -- hanx mcp

Claude 데스크톱 등 MCP 설정 파일을 쓰는 앱

{"mcpServers":{"hanx":{"command":"hanx","args":["mcp"]}}}

hanx를 찾지 못하면 which hanx(Windows는 where hanx)로 확인한 절대 경로를 넣으세요.

2-B. ChatGPT·Claude 웹에 연결

웹·모바일 AI는 내 컴퓨터의 프로그램을 직접 실행할 수 없습니다. hanx connect가 이 컴퓨터의 HanX에 Cloudflare 무료 터널로 접속 주소를 만들어 줍니다. 계정 가입이나 비용은 필요 없습니다.

  1. cloudflared 설치 (처음 한 번)
    macOSbrew install cloudflared
    Windowswinget install --id Cloudflare.cloudflared
    Linuxpkg.cloudflare.com 안내대로 cloudflared 패키지 설치
  2. 연결 시작 
    hanx connect

    작업 폴더(기본 ~/HanX)와 https://….trycloudflare.com/mcp/… 주소가 표시됩니다. 연결하는 동안 터미널 창을 열어 두세요.

  3. AI 앱에 주소 등록

    ChatGPT: 설정 → 앱(Apps & Connectors) → 고급 설정에서 개발자 모드를 켜고, 앱 만들기에서 MCP 서버 URL에 주소를 넣은 뒤 인증은 “없음”을 고릅니다. 개발자 모드 제공 여부는 요금제에 따라 다릅니다.

    Claude: 설정 → 커넥터 → 사용자 지정 커넥터 추가에서 URL에 주소를 넣습니다.

  4. 문서를 작업 폴더에 넣고 요청

    예: “HanX 폴더의 매출.xlsx에 금액 열과 합계 행을 넣어서 새 파일로 저장해 줘.” 결과 파일도 작업 폴더에 저장됩니다. AI 앱에 직접 첨부한 파일은 HanX로 전달되지 않습니다.

안전하게 쓰기
  • HanX는 작업 폴더 안의 파일만 읽고 쓰며, 기존 파일은 교체하지 않고 새 파일로 저장합니다.
  • 연결 주소를 아는 사람은 작업 폴더의 파일을 읽을 수 있습니다. 주소를 공유하지 말고, 끝나면 터미널에서 Ctrl-C로 연결을 닫으세요.
  • 실행할 때마다 주소가 바뀝니다. 다시 연결하면 AI 앱의 커넥터 URL도 새 주소로 바꿔 주세요.
  • 민감한 문서만 따로 모은 폴더를 쓰려면 hanx connect --folder 폴더경로를 사용하세요.
