# PDF editing checks

Use a temporary Python environment with `Tools/pdf/requirements.txt`. Set
`HANX_PDF_PYTHON` to its Python executable and `HANX_PDF_WORKER` to the absolute
worker path. `python -m unittest discover -s Tests/PDFEditor -v` checks real PDF
round trips, original preservation, Korean text, clipping, transforms, stable
batch IDs, image replacement, atomic failure and stale revisions.

Set `HANX_PDF_TEST_CLI` to a newly compiled test CLI to also exercise CLI/MCP.
`desktop/test/pdf-session.test.cjs` additionally needs `HANX_PDF_TEST_FIXTURE`,
a fixture generated by `test_worker.PDFEditorTests.setUp()` (copy its `source`
PDF before `tearDown()`).

Run `Tests/PDFEditor/gui-smoke.cjs` with Electron and the same fixture/CLI variables,
plus `HANX_PDF_TEST_OUTPUT` pointing to a disposable PDF. It tests the real shared
UI, including a mouse drag, and saves a screenshot beside the output.

On macOS, compile `Sources/Core/PDFEditing{Bridge,Session}.swift`,
`Sources/Core/PDFLocalOCR.swift`, `Sources/App/PDFEditingDocument.swift` and
`Tests/PDFEditor/Native/main.swift` to a temporary executable. Run from the repo
root with the fixture variable, `HANX_PDF_WORKER` pointing to test-only
`slow-worker.py`, and `HANX_PDF_REAL_WORKER` pointing to the actual worker.
For the native reader check, use an image-only PDF as the fixture, set
`HANX_PDF_TEST_READ_ONLY=1` and `HANX_PDF_PYTHON=/usr/bin/false`. The reader
opens and renders the page without the editing runtime.

The native test requires the WKWebView editor on opening, then verifies that closing during a first edit waits
for the edit before presenting the unsaved-document confirmation.

No test installs or replaces the user's HanX app.

`document-ui.cjs` uses an optional real multipage PDF supplied through the same environment variables. It checks lazy page thumbnails, T text icons, drawn shape previews, text hit testing above page backgrounds, inline Korean edits, geometry, delete/undo, save-copy integrity and the document import action. Its source fixture is never modified or committed.

`node --test desktop/test/pdf-geometry.test.cjs` checks corner anchors, aspect lock, minimum sizes and all page rotations. `manipulation-ui.cjs` uses the standard three-object fixture and CLI variables to exercise real mouse resizing, Escape cancellation, undo, context-menu deletion, page-number navigation, Page Up and fit width. `HANX_PDF_TEST_SCREENSHOT` optionally captures the selection handles. Run GUI tests one at a time because they use actual window focus.

`input-search-ui.cjs` verifies pending inline text is committed before a native Save action, failed edits restore their draft, uncommitted text triggers the close confirmation, current-page text search selects matches, and type filters limit the object list. The native test also checks that a draft marks the document dirty and Escape clears a canceled draft.

`outline-ui.cjs` optionally tests a locally supplied textbook cover, including whole-title grouping, shared movement, undo and detail toggle. `gestures-ui.cjs` uses the standard fixture to verify full selection, multi-object deletion, undo, actual pointer marquee selection and pinch-wheel zoom while retaining the selection. `desktop/test/pdf-outline.test.cjs` covers outline membership and group pivots. The CMYK paint-state worker regression validates unchanged surrounding artwork after a text replacement.

`test_fonts.py` checks normalized subset names and family/style ranking. Worker tests verify font-family retention for compatible embedded glyphs. `print-ui.cjs` intercepts the OS print request and verifies a private PDF snapshot, non-silent printing and cancellation without sending a job. The native executable supports `HANX_PDF_TEST_PRINT_PANEL=1` to open and cancel a real OS print sheet after the PDF editor initializes. PDF input UI tests verify pending text is committed before printing.

`test_pages.py` covers page rotation, deletion, ordered moves, duplication (independent copies), blank insertion and importing selected pages from another PDF, plus rejection of mixed page/object batches and invalid imports without creating output. `pages-ui.cjs` drives the shared editor page in Playwright's Chromium with a bridge to the real worker (no Electron or compiled CLI needed): thumbnail context menu, drag reordering, import, deletion, undo/redo across page-count changes and the keyboard menu. Set `HANX_PDF_PYTHON`; `HANX_PDF_TEST_SCREENSHOT` optionally saves a screenshot.

`test_paragraph.py` covers `set_paragraph` reflow (unchanged text keeps its lines, longer text wraps within the source width, hard breaks, character breaks for long words, Korean text with any installed Korean font), multi-line `add_text`, rejection cases and a regression where a second font replacement in a saved copy reused an earlier same-named subset and drew wrong glyphs. `paragraph-ui.cjs` drives paragraph selection, the paragraph dialog, the context menu and newline handling in the text dialog. `browser-harness.cjs` is the shared worker-backed host for these Chromium UI checks.

`test_annotations.py` builds a minimal AcroForm fixture (text, checkbox, combo box, read-only field and a note) and checks annotation/field inspection, filling with appearance regeneration, adding highlights/notes/squares with saved appearance streams, restyling, deleting (with popups), and rejection cases. `annotations-ui.cjs` exercises the 주석·양식 panel, on-page field selection, field inputs, note editing, highlight from selected text, note creation, Delete and undo.

`pages-ui.cjs` also covers multi-page selection (Shift range, Ctrl toggle), rotating the selection, extracting it to a separate PDF through the host `extract` action, and deleting it with the Delete key.

`test_images.py` checks WebP/AVIF/GIF/BMP insertion, downscaling and EXIF rotation of a large photo, and the error for formats the engine cannot read. `images-ui.cjs` inserts a WebP file directly and an SVG that the editor page rasterizes and stages as PNG.
